# Ivy, powered by RagaAI — Benefits Verification Landing Page

Three landing page concepts for **Ivy**, the Benefits Verification agent in RagaAI's clinical ops suite. Built in close partnership with leading allergists like Dr. Gary N. Gross.

**Live preview:** https://vj-rag-ship.github.io/ivy-vob-landing/

## Concepts

Use the tab switcher at the top of the page to compare:

- **A · Signature** — RagaAI house style (dark navy + blue→purple gradient, Poppins)
- **B · Editorial** — Stripe/Ramp-inspired (serif italic accents, glassmorphism, product mock)
- **C · Bento** — Linear/Cal.com-inspired (bento grid, before/after, US map of live locations, interactive savings calculator, FAQ)

## What's inside Variant C

- **Live US map** — 12 pinned physician locations with pulsing markers (50 states ready, 100+ locations live)
- **Interactive savings calculator** — sliders for patients/month, minutes per verification, hourly staff cost, CPT codes per patient. Live-computes monthly + annual savings.
- **FAQ** — 7 questions covering pricing, integration time, payer coverage, HIPAA, exception handling, and team origin.

## Key numbers

- **< 15 sec** average verification time (down from 45–60 min)
- **125+ payer plans** live across UHC, Cigna, Aetna, Anthem BCBS, Medicare
- **25+ allergy-specific CPT codes**
- **100+ physician locations** live
- **$80K/month value** per 100 patients

## Stack

Single self-contained `index.html`. No build step. Google Fonts (Poppins, Inter, Instrument Serif, JetBrains Mono).
